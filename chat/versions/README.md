# chat/versions — 시간별 변경 기록

레포에 들어간 모든 변경(코드·설정·문서·규칙)을 시간 순서로 자세히 남긴다. chat room은 대화, 여기는 **무엇이 어떻게 바뀌었는지**의 기록이다.

## 규칙

- 변경 1건(커밋 하나 또는 한 묶음)마다 파일 1개: `YYYYMMDD_HHMM_<버전>_<짧은-제목>.md` (KST, 커밋 시각 기준)
  - 버전은 x.y.z. 코드가 없는 규칙·문서 변경은 `docs`로 쓴다.
- 파일 안에 적을 것:
  1. 시각(KST), 작성자(Claude / claude2 / 사용자), 관련 chat 번호
  2. 커밋 해시(앞 7자리)
  3. 바뀐 파일 목록과 각 파일에서 바뀐 내용(무엇을, 왜)
  4. 동작에 미치는 영향(기본값 변경 여부, 이전과 달라지는 결과)
  5. 검증: 실행한 시험·평가와 수치, 아직 검증 안 한 것
  6. 되돌리는 법(되돌릴 커밋, 끄는 설정)
- 기록 파일은 해당 변경과 **같은 커밋**에 넣는다. 해시는 커밋 뒤에 알 수 있으므로, 직후 짧은 후속 커밋으로 채우거나 다음 기록에 적는다.
- 큰 변경(구조·운영 기본값·버전 y 이상 올림)은 루트 `README.md`의 '큰 변경'과 '현재 코드 상태'도 같이 고친다.
