MAICON 모의고사 1회차 | 문제 2
드론 탑재 센서 기반 비행 상태 분류

[문제 설명]
정찰 드론은 임무 수행 중 정지 비행, 상승, 하강, 회전, 수평 직선 이동 등 다양한 비행 상태를 반복합니다. 드론의 IMU, 각속도, 배터리 및 기타 탑재 센서에서 수집된 시계열 데이터를 분석하여 각 관측 시점의 비행 상태를 분류하는 모델을 구축하세요.

[제공 데이터]
- train.csv: 비행별 식별자(uid), 시간 정보(timestamp), 센서 측정값 및 비행 상태 정답
- test.csv: 비행 상태 정답이 제거된 테스트 관측값
- sample_submission.csv: 제출 예시
※ 출제자가 원본 CSV에서 구성한 학습/테스트 데이터입니다. 열 이름과 결측 여부는 실제 제공 파일을 기준으로 확인하세요.

[예측 대상]
각 행의 flight_state를 아래 5개 클래스 중 하나로 예측합니다.
- IDLE_HOVER: 정지·제자리 비행
- ASCEND: 상승
- DESCEND: 하강
- TURN: 회전
- HMSL: 수평 직선 이동

[모델 및 구현 조건]
1. RandomForestClassifier를 기본 모델로 학습하세요. 다른 분류 모델 및 앙상블을 추가로 비교해도 됩니다.
2. 동일 uid 내부의 시간 순서를 활용하여 이동 평균, 변화량, 구간 통계량 등의 시계열 특징을 만들 수 있습니다. 미래 관측값을 사용하지 않는 것을 원칙으로 합니다.
3. 검증 데이터는 서로 다른 비행(uid)이 학습·검증 양쪽에 섞이지 않도록 분리하세요.
4. 원본 비행 상태 레이블은 위치·고도·방향의 변화로부터 생성되었습니다. 이번 모의고사의 입력에는 상태 레이블이나 그 정답을 직접 재구성하는 파생 정답 열을 포함하지 않습니다. 제공된 센서 입력 열만 사용하세요.

[평가]
Macro F1-score로 평가합니다. 각 클래스의 F1을 동일 가중치로 평균하며, 높을수록 좋습니다.

[제출 형식]
파일명: submission.csv
컬럼: id,flight_state

- 테스트 관측값마다 정확히 한 행을 작성하고, sample_submission.csv의 행 순서를 유지하세요.

## 이번 대회의 제공 구성
- 공개 학습: `data/train.csv` 41,669행, 실제 비행 5개
- 최종 평가: `data/test.csv` 10,499행, 학습과 겹치지 않는 실제 비행 2개
- 복수 상태가 동시에 표시된 원본 2,558행은 제외했고, 단일 상태 52,168행만 사용합니다.
- 원본 uid는 비행 단위를 구별하지 못해, 원본 flight 번호로 `flight_NNN` 형식의 uid를 재정의했습니다. **새 uid가 그룹 분할 기준**입니다.
- 학습과 평가 양쪽에 5개 상태가 모두 포함됩니다. 상태별 수량은 원본 비행의 분포를 유지합니다.
- 위치·고도·자세·yaw·속도와 원본 상태 플래그 등 정답을 직접 재구성하는 열은 입력에서 제외했습니다.
- 미래 관측을 사용하지 마세요. 시간 특징은 uid별로 timestamp와 seq 순서를 확인하고 과거 관측만 사용하세요.

| 컬럼 | 의미 |
|---|---|
| id | 원본 행 기준 고유 ID. 제외 행 때문에 연속 번호가 아닐 수 있음 |
| uid | 재정의한 실제 비행 그룹. 학습·평가에 겹치지 않음 |
| seq | 비행 안의 관측 순서 |
| timestamp | 원본 시간 값. 같은 시간 값에서는 seq로 순서를 구분 |
| wind_speed, wind_angle | 원본 바람 측정값 |
| battery_voltage, battery_current | 원본 배터리 측정값 |
| angular_x, angular_y, angular_z | 원본 각속도 3축 측정값 |
| linear_acceleration_x, linear_acceleration_y, linear_acceleration_z | 원본 선형 가속도 3축 측정값 |
| payload | 원본 탑재 하중 값 |
| flight_state | 학습에만 있는 5개 클래스 정답 |

센서 수치는 원본 값을 유지하며 임의 단위 변환을 하지 않았습니다. uid·id는 숫자 센서로 취급하지 않는 것이 기본 예제의 설정입니다.

## 공통 제출 검증
- 최종 파일: `/workspace/problem02/submission.csv`
- 정확한 컬럼 순서: `id,flight_state`
- sample_submission의 모든 ID를 정확히 한 번씩, 같은 순서로 제출합니다. 누락·추가·중복·순서 변경은 오류입니다.

- 문제 점수는 **100 × raw 평가 지표**입니다. 정답과 정확히 같으면 100점이며 세 문제 합계는 300점입니다.
- 제공 데이터는 읽기 전용이며, 가공 결과·모델·제출은 작업공간에 저장합니다.
