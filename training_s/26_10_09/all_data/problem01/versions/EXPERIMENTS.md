# Problem01 실험 기록 (군용 차량 수량 예측, 지표 = 이미지별 exact-count 정확도)

이번 세션 추가 규칙: yolov8n 만 사용 / train 이미지·라벨을 직접 확인해 맞지 않으면 세부 조정 / 최대 정확도 목표 / 재학습 검증은 30에폭 미만.
정답(test 라벨)은 공개되지 않았다. 점수는 모두 **공개 val 160장** 기준이며 최종 test 점수가 아니다. 이미지 1장 = 0.6%p라 ±2~4%p는 노이즈다.
평균 표기 = conf 0.3~0.55 구간 평균(임계값 한 점의 우연을 줄임), 최고값 = val 에서 고른 임계값(낙관적).

## 현재 메인
- `submission.csv` = `versions/v3_a100_fix_flipTTA_conf0.4.csv` (md5 `6767a7bc…`, 200행, 형식 검증 통과)
- 구성: yolov8n(전이학습, 100에폭, 640, 라벨 1차 보정판 `data_fixed` 기반, `runs/p1/a_fix640/weights/last.pt`) + 좌우 반전 TTA + 박스 융합(WBF, 클래스 무관 군집) + 임계값 0.4.
- val: 평균 0.621, 최고 0.631(@0.4). 반으로 나눠 임계값을 튜닝해 다른 반에서 평가한 정직한 추정은 약 0.61.
- 이전 메인(`_prev_main_backup_v2_gpu640.csv`, 40에폭 원본 라벨, conf 0.3 agnostic)은 val 0.606~0.619로, 차이는 노이즈 수준이다. 정리 데이터 기준을 유지하고 TTA 로 임계값 민감도가 낮아 v3 를 채택했다.

## 라벨 점검 (`audit/AUDIT.md`)
- 형식·기하 오류 없음. 1차: 누락 박스 7개 추가. 2차(임베딩 이상치 + 눈 확인): 사람 박스 삭제 2, 재라벨 3, 이미지 제외 7(미니어처·CG·불확실). train 640→633장.
- tank/military_vehicle, truck/military_vehicle 경계는 원본 라벨 기준이 출처마다 달라 손대지 않음.

## 분포 이동 점검
- 이미지 크기가 출처 단서: 640×640(train+val 262장)은 82%가 빈 라벨이고 tank 외 클래스가 0건. test 는 640×640 이 47.5%(95/200)로 train+val 33%보다 많다.
- 예측 기준 이미지당 총 객체: val 예측 1.16(정답 1.57) vs test 예측 0.76, 모두 0 비율 val 예측 0.42 vs test 예측 0.645. 모두 0 인 test 이미지 중 신뢰도 높은 것들을 눈으로 보면 헬기·항모·자주포 등 4종 밖 객체가 대부분이라 test 에 빈 이미지가 더 많은 것으로 보이나 단정은 못 한다. 
- 따라서 test 점수는 val 점수와 다를 수 있다.

## 알려진 한계 / 남은 선택지
- val 160장이 작아 개선 후보 간 차이를 구분하기 어렵다(시드 간 차이만 ±0.02).
- 선택지: (1) 100에폭 재학습(정리 데이터, 약 17분), (2) train+val 합쳐 재학습(검증 불가), (3) 현재 유지.
