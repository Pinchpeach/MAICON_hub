# 26_10_08 part1 Problem3 실험 기록 (두 손글씨 숫자의 합 예측, Accuracy)

## 현재 메인
- **v1**: 합 라벨 약지도로 학습한 숫자 분류 CNN(왼쪽·오른쪽 반쪽에 공유) + 숫자 1,000장 라벨 손실. 전체 train 10,000쌍 + 숫자 1,000장, 20 에폭, 1시드. `submission.csv` = `versions/v1_weak_sum_cnn_1seed.csv`.
- 홀드아웃(쌍 2,000장) 합 정확도 **0.9860** (v1 과 같은 구성을 8,000쌍으로 학습한 모델).

## 데이터 (관측)
- `train` 쌍 10,000장(28x56, 합만 있음), `digits` 1,000장(28x28, 숫자 0~9, 클래스당 89~109장), `test` 쌍 4,000장. 모두 흑백, 크기 통일, 파일 누락·중복 없음. `sample_submission` 파일명 == test 파일.
- 합 분포는 두 독립 균등 숫자의 합과 거의 같다(합 9 가 10.0%, 합 0 이 1.1%, 합 18 이 0.9%).
- 쌍의 왼쪽·오른쪽 반쪽과 digits 의 밝기·획 두께 분포가 같다(평균 밝기 33.6/33.5/33.4, 획 비율 0.132/0.132/0.131). 쌍의 반쪽과 digits 가 픽셀까지 같은 경우는 없음(누수 없음).
- 규칙상 MNIST 원본 조회(다운로드)는 금지라 사용하지 않았다.

## 방법 비교 (홀드아웃: train 쌍 2,000장의 합 정확도, 나머지 8,000쌍으로 학습)
| 방식 | 검증 합 정확도 | 비용 |
|---|---|---|
| A. 숫자 1,000장만으로 반쪽 분류기 학습(60 에폭) 후 두 숫자 확률을 합성곱해 합 예측 | 0.9720 | 36초 |
| **B. 합 라벨 약지도 + 숫자 1,000장(20 에폭)** | **0.9860** | 314초 |
- B: 숫자 분류기 하나를 왼쪽·오른쪽에 공유하고, 두 숫자의 확률을 합성곱해 합(0~18)의 확률을 만든 뒤 합 라벨로 교차엔트로피를 준다. 숫자 1,000장은 숫자 라벨 교차엔트로피(라벨 스무딩 0.05)로 함께 학습. 증강은 ±2픽셀 이동.
- B 가 A 보다 +1.4%p. 검증 2,000장의 표준오차는 약 0.26%p 로 의미 있는 차이.
- B 모델의 숫자 1,000장 정확도 1.0000(학습에 사용). B 의 검증 오답 28개는 합 0~18 에 고르게 분포(합 9 가 4개로 가장 많음).
- 학습 시간: 8,000쌍 에폭당 약 10초(2 에폭 측정 21초), 10,000쌍 에폭당 약 14~23초(다른 작업과 CPU 경합).

## 제출물 점검
- 4,000행, 컬럼 `filename,sum`, sum 은 0~18 정수, 파일명이 test 와 일치, 노트북 검증 셀(`assert`) 통과. 예측 합 분포는 train 합 분포와 거의 같은 모양(예: 합 9 가 401개로 train 비율 환산 400개).
- 이전 모델(8,000쌍 학습)과 test 예측 일치율 99.52%(불일치 19장). 불일치 장은 모두 합 확률 최대값이 0.9 미만인 불확실한 장이다. 그 모델 기준으로 test 의 7.0%(279장)가 신뢰도 0.9 미만, 55장이 0.6 미만.

## 남은 개선 후보 (미실행)
1. 시드 앙상블(2~3시드): 불확실한 장의 예측 안정화. 학습 시간이 시드당 약 5~6분.
2. 의사 라벨 재학습: 합 라벨이 주어진 쌍에서 (a,b) 사후확률 p(a,b|합)이 높은 쌍을 의사 숫자 라벨로 써서 분류기를 지도학습으로 한 번 더 학습.
3. 에폭 증가, 모델 폭 확대(비용 대비 이득은 미측정).
4. 노트북에 실행 출력이 저장되어 있지 않음(13.13). 마감 때 Restart & Run All 필요.

## 업데이트: 시드 앙상블 비교 (같은 홀드아웃 쌍 2,000장, 8,000쌍으로 학습, 각 20 에폭)

| 구성 | 검증 합 정확도 |
|---|---|
| 시드 0 단독 | 0.9860 |
| 시드 1 단독 | 0.9855 |
| 시드 2 단독 | 0.9860 |

- 단독 3개의 평균 0.9858(최소 0.9855, 최대 0.9860). 3시드 평균과의 차이 +0.0007. 시드 0 대비 +0.0004, 부트스트랩 95% 구간 [-0.30, +0.35]%p -> **노이즈 수준**.
- 시드 간 예측 불일치율 평균 0.85%. 한 시드라도 틀린 장 42개, **세 시드가 모두 틀린 장 18개(0.9%)**, 3시드 평균이 틀린 장 27개(시드 0 은 28개). 오답의 상당수(18/28)는 시드를 바꿔도 같이 틀리는 체계적인 오류라 시드 평균으로 줄지 않는다. 이 방식의 한계는 약 99% 로 보임.
- 비용: 시드 1, 2 학습 각 324초, 295초(8,000쌍). 3시드를 전체 데이터로 학습하면 약 17분(1시드는 약 5.6분).
- 결정: 13.2 규칙(노이즈 수준이면 단순한 기존 버전 유지)에 따라 **메인은 v1(1시드) 유지**. 시드 앙상블은 학습 비용이 3배인데 이득이 확인되지 않음. 2시드 이상이 필요하면 `SEEDS` 값만 바꾸면 됨.

## 업데이트: 남은 오류 분석과 마무리 (세 시드가 모두 틀린 검증 쌍 18개, 전체 2,000장의 0.9%)

- 합 확신도가 낮다: 틀린 예측의 합 확률 평균 0.70, 0.9 이상은 18개 중 3개. 정답 합이 주어졌을 때 (왼쪽, 오른쪽) 숫자 쌍의 사후확률은 0.97~1.00 으로 한 쌍에 집중되어 합 라벨은 일관됨.
- 모델이 읽은 숫자와 정답 합을 만족하는 가장 그럴듯한 숫자가 다른 쪽은 보통 한쪽뿐. 불확실한 쪽은 왼쪽 10건, 오른쪽 8건으로 치우치지 않음.
- 혼동 쌍(읽은 숫자 -> 추정 숫자): 4->9 2건, 2->7 2건, 1->7, 1->8, 8->0, 6->0, 5->3, 9->4, 7->1, 0->6, 4->6, 6->8, 4->8, 8->2, 2->1, 5->8 이 각 1건. 정답합-예측합 차이는 -8~+7 로 고르게 분포.
- 이미지 확인(눈으로 본 해석, 확정 아님): 오른쪽이 5처럼 보이는 3(#1), 윗부분이 열린 4 처럼 보이는 9(#2), 1처럼 보이는 7(#3), 이중 고리 모양의 0(#5) 등 필기가 모호한 경우가 많았고 라벨이 틀려 보이는 경우는 뚜렷하지 않았다.
- 해석: 이미지만으로 구분하기 어려운 경계 사례라 이 방식의 천장은 약 99% 로 보인다. 시드 앙상블로 줄지 않은 이유와 일치.
- 미실행 후보: 합 라벨이 정해 주는 숫자를 의사 숫자 라벨로 써서 약 1.7만 개 숫자로 분류기를 지도학습(예상 +0.2~0.3%p, 미측정). 13.11 에 따라 시도하지 않고 마무리.
