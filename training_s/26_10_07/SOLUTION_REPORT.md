## 3. 26_10_07 모의 대회

환경: Jupyter, 문제 3개 합계 90분, CPU, 인터넷 가능. 허용 라이브러리는 일반 라이브러리와 공개 사전학습 모델이고, 금지는 LLM으로 test 직접 예측·test 수작업 라벨링·원본 공개 데이터셋 정답 조회입니다.
숨은 AI 지시문은 3개 노트북 모두 발견되지 않았습니다. P1은 처음에 `train.csv`가 없어 진행하지 못했고, 사용자가 파일을 넣어 준 뒤 시작했습니다.

### P1 다이아몬드 가격 (RMSLE)

**데이터 점검**: `cut`의 소문자 변형(`ideal` 등), `clarity`의 끝 공백(`VS2 `), `depth`·`table` 결측 약 3%, `x/y/z`가 0인 행(train 5/4/13개), `y` 최댓값 58.9 이상치, id 제외 중복 행 56개.

**해결 과정과 결과** (5-Fold CV RMSLE, 낮을수록 좋음)

| 단계 | 구성 | CV RMSLE |
|---|---|---|
| 정리 + 순서 인코딩, HGB | 표기 정리, 0·이상치 결측 처리, `log1p(price)` 타깃 | 0.0896 |
| + `depth`/`z` 복원 | `depth = 100×z/평균(x,y)` 관계로 복원 | 0.0895 |
| + 파생 특징 | 부피, 로그 캐럿, 등급×캐럿 교호작용 등 | 0.0851 (가장 큰 효과) |
| v1: HGB + RF 평균 | | **0.0833** (재측정 0.0831, 환산 약 78.9) |
| v2: CatBoost 2종 + ExtraTrees | 순서 인코딩 / 범주형 직접 입력 | 0.0814 (약 79.3) |
| **v3: v2 + 캐럿 추세 제거 타깃** | `log1p(price) − (a·log(carat)+b)`를 학습 후 복원 | **0.0810** (약 79.4) |

**분석**: 오차 상위 1% 행이 전체 제곱오차의 20.6%, 상위 5%가 45.9%를 차지합니다. 라벨 노이즈로 보이는 행이 많아 개선 천장이 낮습니다. 캐럿 1.5 이상, `I1`·`SI2` 구간에서 오차가 큽니다.

**기각**: L1 손실(단독 0.0869), ExtraTrees 단독(0.0871), 노이즈 행 제거 학습(0.0827로 악화), 캐럿 경계 특징(0.0823→0.0820, 타깃 변환과 함께 쓰면 추가 이득 없음), NNLS 가중·Ridge 스태킹(0.0813, 균등 평균과 차이 없음).

**주의**: CatBoost는 문제의 허용 목록에 이름이 없습니다("일반 라이브러리"). 대체안은 sklearn만 쓰는 v1이며 `versions/notebook_v1_hgb_rf.ipynb`에 보존했습니다(HGB+RF에 타깃 변환을 적용하면 0.0831→0.0827이라는 실험값이 있으나 제출물은 아님).

### P2 영화 리뷰 감성 (Accuracy)

**데이터 점검**: 결측 없음, 라벨 1:1(10,032/9,968), 길이 분포가 train·test에서 비슷, train·test 중복 없음.

**해결 과정과 결과** (5-Fold 층화 CV 정확도)

| 단계 | 구성 | CV |
|---|---|---|
| 단일 모델 | LR 0.8292, SVM 0.8310, Complement NB 0.8443, Multinomial NB 0.8426, NB-LR 0.8257 | |
| v1 | NB 3종 순위 평균(상위 50.2%를 긍정) | **0.8478** |
| 기각 | LR+SVM+CNB 확률 평균 | 0.8386 (NB 확률 보정이 나빠 희석) |

**v1 이후 개선 시도**
1. **정규화·NB 조정(A), 스태킹(B)**: 반복 문자 축약 +0.0004, alpha 0.2 +0.001, 스태킹 0.8461(v1보다 낮음) → 기각.
2. **글자 BiGRU(RNN)**: 단독 0.8056. NB와 합친 앙상블 0.8499(+0.21%p)는 표준오차 약 0.25%p라 노이즈 수준. 길이별 버킷팅으로 에폭 53초 → 9.5초로 단축. 이 시도는 v1 유지로 결론.
3. **오류 분석**(OOF 오류율 15.2%): 역접 문장 17.4%, 불확실 구간(확신 하위 20%)에 오류율 39%가 집중, 확신이 높은 오류는 대부분 반어·라벨 노이즈.
4. **오류 패턴 겨냥 전처리**: 슬랭 표준화 −0.10%p, 이모티콘 토큰화 −0.29%p, 점수 토큰화 ±0, 마지막 절 이어 붙이기 전부 하락. 글자 n-gram이 이미 직접 학습하는 표현을 토큰으로 바꾸면 정보가 줄어든다고 해석.
5. **세부 조정**: CNB `min_df=1`, alpha 0.3 → 0.8472, MNB `char` 분석기 → 0.8463. 두 모델 앙상블(v3) 0.8496, 역접 문장에만 마지막 절 모델을 섞은 v3g 0.8509(역접 문장 정확도 0.8256→0.8342). 같은 OOF로 고른 값이고 95% 구간이 0을 포함해 후보로만 기록.
6. **직접 추출한 표현 특징(fork 세션)**: 각 fold 학습 부분에서 자주 나오는 글자 1~3gram·어절 1~2gram의 긍정/부정 로그오즈로 24개 특징을 만들어 HGB에 입력(특징만으로 0.8304). NB 3종에 합친 **v2가 0.8487**(+0.0009, 노이즈 수준). 추출된 상위 표현: 긍정 `잼나`·`굿굿`·`짱!`, 부정 `최악`·`아깝다`·`1점도`·`노잼`.
7. **사전학습 모델 임베딩(fork 세션)**: `klue/roberta-base`(442.6MB)를 받아 속도를 쟀는데 약 39건/초로 3만 문장에 약 13분이 걸려 사용자 지시로 중단했습니다(성능 미측정). 모델은 HF 캐시에 남아 있습니다.

**최종**: 현재 `submission.csv`는 v2(표현 특징 HGB 포함)입니다. v1과 test 예측이 97.9% 같습니다. 이 단계의 모든 개선은 fold 노이즈 범위 안이며, 이 방식의 한계는 약 0.85로 보입니다.

### P3 패션 이미지 (Accuracy)

**데이터 점검**: 결측 없음, 클래스 거의 균등(1,165~1,244), 픽셀 범위 0~255, train·test 중복 없음.

**해결 과정과 결과**
- **비용 측정 먼저**: 2 에폭 측정(에폭당 약 10초, 9,600장) 후 12 에폭 홀드아웃 → 정확도 0.9117(시드 0). 최종 학습은 전체 train 2시드.
- **구조**: Conv-BN-ReLU×2 + MaxPool 블록 3개(채널 32/64/128), 좌우반전과 ±2픽셀 이동 증강, 라벨 스무딩 0.05, AdamW + OneCycle, 좌우반전 TTA.
- **검토**(홀드아웃 2,400장): 가방 0.987, 바지 0.984, 샌들 0.979 등은 높고, **셔츠 recall 0.725**가 가장 낮음. 셔츠↔티셔츠 59건, 풀오버·코트·드레스→셔츠 47건 등 모양이 비슷한 상의 혼동이 오류의 대부분. 신뢰도 0.6 미만이 9.5%이고 그 구간 정확도는 0.561.
- **개선 실험** (같은 홀드아웃)

| 설정 | 정확도 | 셔츠 recall / precision |
|---|---|---|
| 12 에폭 시드 0 | 0.9117 | 0.725 / 0.693 |
| 12 에폭 시드 1 | 0.9062 | 0.682 / 0.697 |
| 12 에폭 2시드 평균 | 0.9092 | 0.708 / 0.688 |
| **20 에폭 시드 0** | **0.9167** | 0.725 / 0.722 |
| 12 에폭 시드 0 + 20 에폭 시드 0 평균 | 0.9171 | 0.738 / 0.720 |

  - 시드 확대는 효과가 확인되지 않았음: 불확실 구간에서 두 시드가 29.8% 다르게 예측하지만 둘 다 정확도가 낮아(0.56/0.54) 원래 어려운 샘플로 판단.
  - 20 에폭은 같은 시드에서 +0.5%p이고 셔츠 precision이 0.693→0.722로 개선. 다만 시드 변동 0.55%p, 홀드아웃 표준오차 약 0.58%p라 확정은 아님. 두 번째 시드로의 재검증은 수행하지 않음.
- **최종**: 사용자 결정에 따라 측정된 최고 구성의 에폭 수(20)로 전체 train 2시드를 학습. 학습 560초. v1과 test 예측이 97.36% 같고(132장 차이), 차이는 주로 상의 경계(티셔츠↔셔츠, 코트↔셔츠).

## 5. 교훈

1. **라벨 노이즈가 천장을 정한다.** P1(오차 상위 1%가 제곱오차 20.6%)과 P2(확신이 높은데 틀린 반어·라벨 노이즈) 모두 모델을 바꿔도 이득이 거의 없었습니다. 오류 분석을 먼저 하면 헛수고를 줄입니다.
2. **CV는 train 분포 안에서만 믿을 수 있다.** 25 P3에서 CV 0.912가 test 0.673으로 떨어졌고, 원인은 양성 비율과 어휘 이동이었습니다. 제출 전에 test 분포를 비교하고 임계값 규칙을 정직하게 기록해야 합니다.
3. **전처리는 모델이 이미 학습하는 정보를 지우면 오히려 해롭다.** 글자 n-gram은 `ㅠㅠ`·`ㅋㅋ`·점수 표현을 직접 학습해서, 토큰 치환이 모두 CV를 낮췄습니다.
4. **앙상블 이득은 작을 때가 많다.** 노이즈 수준(+0.1~0.3%p)의 차이는 부트스트랩 구간으로 확인하고 단순한 기존 버전을 유지하는 규칙이 유효했습니다.
5. **비용은 먼저 측정한다.** BiGRU는 버킷팅으로 5배, YOLO는 60 에폭 반복(약 55분)이 과했던 사례였습니다. 에폭 수와 반복 학습은 사전에 따져야 합니다.
6. **같은 폴더를 두 세션이 동시에 쓰지 않는다.** 이번 병행 작업에서 서로의 결과와 기록이 덮어써졌습니다. 작업을 나눌 때는 폴더를 분리하거나 한쪽이 끝난 뒤 이어야 합니다.
7. **정답은 평가에만 쓴다.** 정답을 본 뒤의 변경(임계값, 사전 확장)은 동기와 오염 가능성을 기록해야 점수를 정직하게 해석할 수 있습니다.
