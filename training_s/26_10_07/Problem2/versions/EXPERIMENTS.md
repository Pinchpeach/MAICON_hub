## 오류 분석 → 전처리 → 세부 조정 (CV 5-Fold seed 42, train OOF 기준)

### 오류 분석 (v1 OOF, 오류율 15.2%, 긍정/부정 오분류율 15.2%/15.3%로 대칭)
- 역접 표현(지만/근데/그래도 등) 포함 문장 오류율 17.4% (n=3,251, 미포함 14.8%). 의문(?) 포함 16.6%.
- 길이별 오류율: 10자 미만 16.2%, 10~20자 16.5%, 20~40자 15.2%, 40~70자 14.2%, 70자 이상 13.4%.
- 확신도 5분위별 오류율: 가장 낮은 20% 구간 39.1% -> 가장 높은 20% 구간 1.7% (오류가 불확실 샘플에 집중).
- 확신이 높은 오류의 다수는 반어/라벨 노이즈(긍정 라벨인데 "쓰레기 영화라 한 사람들을 비난" 같은 문장, "가슴 따뜻해지는 명작.." 이 부정 라벨 등)로 개선 불가능한 상한으로 판단.

### 전처리 시험 (CNB 단일, 기준 0.8446)
| 전처리 | CV | 비고 |
|---|---|---|
| 슬랭/오타 표준화(노잼/꿀잼/쓰렉 등) | 0.8436 | -0.10%p |
| 이모티콘 토큰(NEGFACE/CRYFACE/LOLFACE) | 0.8417 | -0.29%p |
| 점수 토큰(HIGH/MID/LOWSCORE) | 0.8445 | ±0 |
| 위 전부 | 0.8424 | -0.22%p |
| 본문 + 마지막 절(역접 뒤) 이어 붙임 w=0.5/1.0/1.5 | 0.8428 / 0.8404 / 0.8366 | 전부 하락 |
- 해석: 글자 n-gram 이 이모티콘/초성/점수 표현을 이미 직접 학습하므로 토큰으로 치환하면 정보가 줄어듦. 결론: 전처리는 반복 문자 축약만 유지.

### 모델 세부 조정
- CNB(char_wb 1~4 TF-IDF): alpha 0.2/0.3 -> 0.8449/0.8452, min_df=1 -> **0.8472**(최고), min_df=3 -> 0.8431, (2,4) 0.8433, (1,3) 0.8431, analyzer=char 0.8466.
- MNB(이진 카운트): analyzer=char(1,4) alpha 0.5 -> **0.8463**(최고), char_wb alpha 0.2/1.0 -> 0.8410/0.8423.
- 단어 단위 NB는 단독 0.748/0.749로 약하고 앙상블에 넣으면 하락(0.8411, 0.8274) -> 제외.
- 마지막 절 전용 CNB 단독 0.8213.

- 판단: 오류 분석이 가리킨 역접 문장은 실제로 개선됨(+0.86%p)이나 전체 이득은 작고, 파라미터(min_df, 가중치)를 같은 OOF 로 골랐으므로 낙관적. 신뢰 구간이 0을 포함하므로 13.2 규칙(노이즈 수준이면 단순한 기존 버전 유지)에 따라 당시 판단은 v1 유지(이후 v2 로 교체됨, 위 "현재 메인" 참고), v3/v3g 는 후보로 기록.

## v2 (메인): v1 + 직접 추출한 표현 특징(LexFeatures) HGB, 반복 문자 정규화
- 추출: 각 fold 학습 부분에서 자주 나오는(min_df 12) 글자 1~3gram, 어절 1~2gram 의 긍정/부정 로그오즈를 계산(검증 누수 없음). 극성 상위 400개씩의 적중 수, 로그오즈 합/평균/최대/최소, 강한 극성 표현 수 + 직접 설계한 표현 특징(길이, !, ?, ~, ㅋ/ㅎ/ㅠ 수, 반복 길이, 숫자/평점, 문장 끝 형태) 총 24개.
- 추출된 상위 표현: 긍정 '잼나', '잊을', '굿굿', '♥♥', '짱!', 부정 '최악', '아깝다', '1점도', '노잼', '유치하고'.
| 구성 | CV acc |
|---|---|
| 표현 특징 24개만 쓴 HGB | 0.8304 |
| TF-IDF + 표현 특징 LR | 0.8359 (TF-IDF LR 0.8292 보다 +0.007) |
| NB 3종 + 반복문자 정규화 | 0.8481 |
| NB 3종 + TF-IDF·표현 LR | 0.8484 |
| **NB 3종 + 표현 특징 HGB (v2, 메인)** | **0.8487** (환산 약 84.9) |
| NB 3종 + 둘 다 | 0.8478 |
- 결론: 표현 특징은 단독으로도 0.83 을 내지만 n-gram 모델이 이미 같은 신호를 쓰고 있어 앙상블 이득은 +0.0009 (fold 노이즈 수준). v1 대비 test 예측이 97.9% 동일.
