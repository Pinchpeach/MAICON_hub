# solution_new: 반어법 거름망(flip) 시도 기록

**결론: 채택하지 않음.** 기존 최종 해(v2)를 그대로 유지했고, `submission.csv` 는 `submission_base.csv`(= `../submission.csv`, v2)와 동일하다.

## 아이디어 (사용자 제안)
1. train 에서 반어법 문장을 모아 `train_van.csv` 생성
2. 반어 탐지 모델(반어=1, 아니면 0) 별도 학습
3. 기존 최종 모델은 유지하고 결과와 탐지 모델 결과를 비교
4. 반어로 판정된 문장은 기존 긍정/부정 예측을 반대로 바꿔 최종 값 도출

## 1. train_van.csv (401행, 전체의 2.00%)
- 선택 기준(자동): v1 5-Fold OOF 예측(NB 3종 순위 평균)이 **라벨과 반대이고 확신도 `|s-0.5| >= 0.25`** 인 문장. 20,000개를 전부 손으로 분류할 수 없어 수동 라벨링 대신 이 기준을 썼다.
- 수동 검수: 이 집합에서 무작위 45개를 직접 읽고 분류함(`train_van_audit.csv`).

| 분류 | 수 | 의미 |
|---|---|---|
| irony_defense | 18 (40%) | 반어·옹호·표면 감성과 반대 ("이 영화 욕하지마라", 비평가를 욕하는 긍정 리뷰, "케빈코스트너씨 … 떠나도 좋습니다") |
| label_noise | 14 (31%) | 문장은 단순한데 라벨이 반대이거나 중립/무의미 ("엄청재밌는영화입니다"가 라벨 0, "어쩌라고"가 라벨 1) |
| contrast | 13 (29%) | 역접·복합 문장 (모델의 약점) |
- 즉 "확신하는데 틀린" 집합의 진짜 반어는 약 40% 뿐이고 나머지는 라벨 노이즈와 역접이다.

## 2. 반어 탐지 모델 (5-Fold CV, 반어=1 / 나머지 0, LR class_weight=balanced)
| 탐지기 | 반어 탐지 AUC |
|---|---|
| 텍스트 + 모델 점수 (C=1 / C=0.2) | 0.853 / 0.858 |
| 텍스트만 | 0.587 |
- 점수를 넣은 AUC 는 "확신도가 높을수록 반어"가 되도록 라벨을 정의한 데서 오는 착시이다. 텍스트만으로는 0.587 로 약하다.

## 3. 뒤집기 시뮬레이션: 탐지 점수 상위 k 개를 뒤집었을 때 (기준 v1 OOF 정확도 0.8478)
- 뒤집은 문장 중 **원래 모델이 실제로 틀렸던 비율(정밀도)** 이 0.5 를 넘어야 이득이다.
- 텍스트+점수: k=10~800 에서 정밀도 0.08~0.16, 정확도 변화 -0.04%p ~ -3.16%p (전부 하락).
- 텍스트만: k=10 정밀도 0.40, k=100 0.21, k=800 0.17. 정확도 변화 -0.01%p ~ -2.62%p (전부 하락).

## 4. 직접 정의한 반어 신호 규칙으로 뒤집기 (train 전체, 현재 정확도 → 뒤집으면)
| 신호 | n | 현재 정확도 | 뒤집으면 | 전체 정확도 변화 |
|---|---|---|---|---|
| 옹호/비난 대상 지칭(욕하지마·무뇌·뭐냐·니들·너희 등) | 239 | 0.812 | 0.188 | -0.745%p |
| 명령형 금지(하지마·마라·마세요 등) | 283 | 0.883 | 0.117 | -1.085%p |
| 비꼼 종결(떠나도 좋·잘 가시·굿.. 등) | 77 | 0.896 | 0.104 | -0.305%p |
| 의문형(`??`, 문장 끝 `?`) | 812 | 0.826 | 0.174 | -2.650%p |
| 역접(참고) | 1,479 | 0.815 | 0.185 | -4.655%p |
| 인용/반박(라고들·사람들 등) | 264 | 0.811 | 0.189 | -0.820%p |
- 모델 확신도 0.2 이상으로 한정해도 현재 정확도가 0.881~0.925 로 더 높아서 결과는 같다. 짝수/홀수 행으로 나눠도 동일(옹호/비난 신호 0.885/0.878).

## 왜 안 되었나
- 반어 신호가 들어간 문장의 대부분(81~93%)은 현재 모델이 이미 맞힌다. 그 신호만으로 뒤집으면 맞던 것을 틀리게 만든다.
- 진짜 반어와 라벨 노이즈, 역접이 한 집합에 섞여 있고 텍스트로 구분되지 않는다(텍스트만 AUC 0.587).
- 뒤집기가 이득이려면 정밀도 50% 초과가 필요하지만 어떤 방식에서도 최대 40%(k=10)였다.

## 주의
- OOF 점수로 라벨을 만들었기 때문에 탐지 AUC 는 낙관적이다(결론은 정반대 방향이라 영향 없음).
- 신호 규칙은 검수 표본을 보고 정했으므로 train 안에서의 수치일 뿐이다.

## 재현
- `experiments/van_cand.py`(후보 개수와 검수 표본), `van_cv.py`(탐지기 CV와 뒤집기 시뮬레이션), `van_cues.py`(신호 규칙). `v1_oof_score.npy` 는 v1 의 OOF 순위 평균 점수.

# 추가 검증: "1차 모델이 긍정으로 예측한 문장"만 2차 검증기로 검사 (뒤집기에 집착하지 않음)

## 설정
- 대상: train 에서 v1 OOF 예측이 긍정인 10,032개. 이 중 실제 라벨이 부정인 "틀린 긍정"이 1,522개(15.2%), 그 중 확신 오류(train_van의 긍정 예측 부분)가 184개.
- 2차 검증기: 이 대상 안에서만 "틀린 긍정 여부"를 학습(LR, class_weight=balanced), 5-Fold CV. 입력은 텍스트(글자 1~4gram + 어절 1~2gram), 선택적으로 1차 점수와 반어 단서 8개(역접, 옹호/비난, 비꼼 종결, 의문, 말줄임, 한정 표현, 부정 평가어, 이모티콘).

## 결과 (긍정 예측 10,032개, 무작위 기준 AP = 0.152)
| 검증기 | AUC(틀린 긍정) | AP | 상위100 정밀도 | 상위500 정밀도 |
|---|---|---|---|---|
| **1차 점수만 (낮을수록 의심)** | **0.803** | **0.383** | 0.44 | 0.49 |
| 텍스트 검증기(점수 미사용) | 0.704 | 0.272 | 0.35 | 0.35 |
| 텍스트+점수 검증기(LR) | 0.791 | 0.360 | 0.43 | 0.43 |
| 순위합 1차 점수 + 0.5 x 텍스트 | 0.796 | 0.367 | 0.46 | 0.44 |
| 순위합 1차 점수 + 0.25 x 텍스트 | 0.802 | 0.377 | 0.40 | 0.44 |

## 1차 점수 구간 안에서도 텍스트 검증기가 구분하는가 (점수 미사용 검증기)
| 1차 점수 s | n | 틀린 긍정 비율 | 텍스트 검증기 AUC |
|---|---|---|---|
| 0.50~0.55 | 1,033 | 0.463 | 0.477 |
| 0.55~0.60 | 996 | 0.338 | 0.522 |
| 0.60~0.70 | 2,026 | 0.199 | 0.538 |
| 0.70~0.80 | 2,043 | 0.094 | 0.573 |
| 0.80 이상 | 3,934 | 0.028 | 0.614 |

## 해석
- **검증기의 겉보기 성능(AUC 0.70~0.79)은 대부분 1차 모델의 불확실성을 따라간 것**이다. 1차 점수만 쓸 때(0.803)가 가장 좋고, 텍스트를 더해도 개선되지 않는다.
- 1차 점수가 비슷한 구간 안에서 텍스트만으로 틀린 긍정을 가려내는 능력은 거의 없다(경계선 구간 AUC 0.48~0.52, 높은 점수 구간에서도 0.57~0.61). 반어를 따로 알아보는 독립적인 신호는 이 데이터와 특징으로는 확인되지 않았다.
- 1차 점수가 낮은 긍정(s<0.6) 2,029개 중 틀린 긍정은 40.2%이며, 전부 뒤집으면 정확도 -1.995%p. 가장 의심스러운 구간에서도 정밀도가 50%에 못 미쳐서 뒤집기는 이득이 없다(앞선 결과와 일치).
- 즉 "의심 순위"를 매기는 용도로는 1차 점수가 이미 가장 좋은 지표이고, 2차 검증기는 새로운 정보를 더하지 못한다.

## 테스트 점수 (뒤집지 않음, 참고용)
- `van_verifier_test_scores.csv`: 현재 제출(v2)의 긍정 5,016개에 대한 검증기 점수(텍스트+점수+단서). 제출 값은 바꾸지 않았다.
- train OOF 상위 100개 기준값(0.87) 이상인 테스트 긍정은 77개. 점수 상위 12개를 읽어 보면 "소수 마니아들의 영화. 그들만 보고 그들만 평점을 매기니 점수가 높을수밖에", "어릴때 보던 백터맨시리즈가 더낫다", "4점이 적당하다", "남상미의 열연만이 돋보인다", "볼거리 하나 있었다" 처럼 비교·한정 표현, 비꼼, 짧은 칭찬이 섞여 있다. 약 절반이 부정 의도로 읽히지만 test 정답이 없어 정량 검증은 불가능하다(질적 확인).
- train 에서 상위로 올라온 문장 25개 중 실제 라벨이 부정인 것은 9개(36%)였다.

## 재현
- `experiments/van_pos.py`(검증기 CV와 테스트 점수), `van_pos2.py`(점수 구간별 분석, `van_pos.py` 와 같은 폴더에서 실행).

# 추가 시도: 반어 의심 문장은 기존 모델이 아니라 NN 전문가가 처리 (라우팅)

## 구조
- 게이트: 1차 모델(v1) 점수 기준으로 "의심 구간"을 정의. A = 긍정 예측이면서 s<0.6(경계선 긍정, n=2,029), B = |s-0.5|<0.1(경계선 전체, n=4,041).
- 전문가 NN: 의심 구간 문장만으로 학습한 별도 NN(글자 단위 BiGRU 또는 글자 CNN, 선택적으로 1차 점수를 입력). 게이트 안의 문장은 NN 예측으로 대체하고 나머지는 기존 모델을 유지.
- 평가: 게이트 안 문장을 5-Fold 로 나눠 전문가 NN 을 학습·예측(OOF), 게이트 안 정확도와 전체 정확도를 1차 모델과 비교.

## 사전 확인: 전체 데이터로 학습한 일반 BiGRU 를 의심 구간에 쓰면 (저장된 OOF 사용)
| 게이트 | n | 1차 | BiGRU | 전체 정확도 변화 |
|---|---|---|---|---|
| A 경계선 긍정 | 2,029 | 0.598 | 0.594 | -0.045%p |
| B 경계선 전체 | 4,041 | 0.609 | 0.587 | -0.445%p |
| C |s-0.5|<0.2 | 8,076 | 0.703 | 0.651 | -2.115%p |
| D 긍정 예측 & s<0.7 | 4,055 | 0.700 | 0.659 | -0.815%p |
- 두 모델이 다르게 예측하는 문장(게이트 A 39.4%)에서 BiGRU 가 맞는 비율 49.4%(동전 던지기).

## 결과: 의심 구간에 특화해 학습한 NN 전문가 (게이트 안 5-Fold OOF)
| 게이트 | NN | 점수 입력 | 게이트 안 정확도 | 1차 대비 | AUC | 전체 정확도 변화 |
|---|---|---|---|---|---|---|
| A (1차 0.598 = 전부 긍정으로 찍는 기준 0.598) | BiGRU(시드 2) | X | 0.568 | -3.0%p | 0.521 | -0.305%p |
| A | CNN | X | 0.566 | -3.3%p | 0.517 | -0.330%p |
| A | CNN | O | 0.571 | -2.8%p | 0.522 | -0.280%p |
| A | BiGRU | O | 0.557 | -4.1%p | 0.516 | -0.420%p |
| B (1차 0.609, 찍기 0.511) | CNN | X | 0.523 | -8.6%p | 0.529 | -1.735%p |
| B | CNN | O | 0.561 | -4.9%p | 0.586 | -0.985%p |
- 모든 구성에서 기존 모델보다 낮고, AUC 는 0.52~0.59 로 우연에 가깝다.
- 게이트 A 에서는 1차 모델의 정확도(0.598)가 "전부 긍정으로 찍기"와 같다. 즉 경계선 긍정 구간에서 1차 모델도 구분 능력이 거의 없고, NN 도 이 구간 2천 문장에서는 배울 신호를 찾지 못했다.

## 해석
- 의심 구간은 반어와 라벨 노이즈, 역접 문장이 섞인 곳이라 표본 2~4천 개로 처음부터 학습한 NN 이 일반화할 신호를 얻지 못한다. 점수를 입력으로 주면 조금 나아지지만(B: 0.523 -> 0.561) 그것도 1차 점수를 다시 쓰는 효과이고 1차 모델(0.609)에는 못 미친다.
- 이 데이터에서는 반어를 가려내는 단계(게이트)가 약하고(텍스트 검증기 구간 내 AUC 0.48~0.52), 가려낸 뒤의 NN 도 학습 표본이 부족하다. 두 단계 모두 병목이다.

## 비용 기록
- BiGRU 1구성(시드 2, 5-Fold, 2천 문장, 12 에폭) 349초, 시드 1이면 148초. CNN 은 2천 문장 약 40초, 4천 문장 약 80초(시드 1). 8개 구성 전체(약 45분)는 첫 구성의 결과(AUC 0.52)를 보고 중단하고 5개 구성으로 줄여 실행.
- 재현: `experiments/route_check.py`(일반 BiGRU 라우팅), `expert_nn.py`(첫 구성만 실행 후 중단), `expert_nn2.py`(보고한 5개 구성).

## 남은 가능성
- 학습 표본이 병목이므로, 반어 판별에 필요한 의미 이해를 외부에서 가져오는 쪽(한국어 사전학습 모델 임베딩/소형 모델)이 유일하게 구조가 다른 시도이다(다운로드 허락 필요, 효과 미측정).

# 이중 거름망 계속 (1번 -> 2번 순서)

공통 평가: 5-Fold(StratifiedKFold seed 42, 기존 v1 과 같은 분할), 기준은 같은 분할에서 NB 3종(cnb+mnb+nblr 순위 평균)을 그대로 학습한 정확도 0.8475. 중첩 평가(바깥 fold 의 학습 부분 안에서 내부 5-Fold OOF 로 1차 점수를 만들어 누수 없음).

## 1번: 학습 데이터에 거름망 적용 (노이즈 의심 행 제거 후 재학습)
- 1단: 학습 부분의 내부 OOF 에서 "확신하는데 틀린" 행(확신도 |s-0.5| >= t)을 노이즈 의심으로 판정 -> 2단: 그 행을 빼고 NB 3종 재학습.
| 설정 | CV 정확도 | 기준 대비 | 부트스트랩 95% | 제거 행 |
|---|---|---|---|---|
| 기준 | 0.8475 | | | |
| 정제 t=0.2 | 0.8472 | -0.025%p | [-0.27, +0.22]%p | fold 당 545개(3.4%) |
| 정제 t=0.3 | 0.8466 | -0.085%p | [-0.28, +0.11]%p | fold 당 195개(1.2%) |
- 결과: 효과 없음. 학습에서 노이즈를 걸러도 test 라벨의 노이즈는 그대로라 평가 정확도가 오르지 않는다.

## 2번: 전체 데이터로 학습하는 잔차 NN
- 구조: 최종 로짓 = beta x (1차 점수 - 0.5) x 8 + NN 보정 항. NN(글자 CNN, 마지막 층 0 초기화)은 1차 모델의 약점 보정만 학습. 학습은 학습 부분 전체(약 16,000개), 8 에폭, seed 0 한 번. 1차 점수는 내부 OOF 점수(학습 행), 검증 행은 학습 부분으로 만든 NB 3종 점수.
- 어려운 문장 가중치 w = 1 + alpha x (1 - 2|s-0.5|) (alpha 로 비교).
| alpha | 잔차 NN 정확도 | 기준 대비 | 부트스트랩 95% | 경계선(|s-.5|<.1) 정확도 | 바뀐 예측 중 맞아진 것 |
|---|---|---|---|---|---|
